# Team Backlogs (Digitized)

Handwritten notebook pages digitized into a structured backlog for planning and tracking.

**Source:** 11 notebook photos (see [`assets/`](./assets/))  
**Planning snapshot:** 1403-05-17 (Solar Hijri)

## Files

| File | Purpose |
| --- | --- |
| [`BACKLOG.md`](./BACKLOG.md) | Open / in-progress items, categorized |
| [`DONE.md`](./DONE.md) | Completed or struck-through items |
| [`sources/`](./sources/) | Page-by-page transcriptions (original wording preserved) |

## How markers were interpreted

| Notebook mark | Meaning used here |
| --- | --- |
| Strike-through / blue `x` | Done |
| `*`, `o`, `→`, letters (`A`, `S`, `SD`, `D`) | Open (letter may be owner/area) |
| Numbers (`1`, `2`, `10`, …) | Effort / priority notes from the notebook |
